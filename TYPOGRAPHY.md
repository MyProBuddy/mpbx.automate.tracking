# Typography System — MPBX Tracking

Derived from Callivio CRM SaaS design guidelines (Urbanist typeface, clear hierarchy, fast scanning).

## Typeface
- **Font:** Urbanist (Google Fonts)
- **Weights used:** 400 (Regular), 500 (Medium), 600 (SemiBold), 700 (Bold), 800 (ExtraBold)

## Scale

| Role              | Size   | Weight | Letter-spacing | Notes                          |
|-------------------|--------|--------|----------------|--------------------------------|
| Display / Hero    | 32px   | 800    | -0.03em        | Page headline, one per screen  |
| Section heading   | 22px   | 700    | -0.025em       | Card titles, section titles    |
| Subheading        | 15px   | 600    | -0.02em        | Sub-labels, group headers      |
| Body              | 13px   | 400    | -0.01em        | Descriptions, paragraph text   |
| UI / Nav label    | 12px   | 500    | -0.01em        | Nav pills, buttons, tabs       |
| Eyebrow / Badge   | 10px   | 700    | +0.08em        | UPPERCASE category labels      |
| Caption / Meta    | 11px   | 400    | 0              | Secondary info, timestamps     |

## Brand / Logo
- **"MPB"** — 18px, 700, gradient orange→red
- **"x"** — 18px, 400, accent pink
- **"Tracking"** — 12px, 400, gradient red→purple

## Color usage (typography)
- Primary text: `#0D0D14` (near-black)
- Secondary text: `#7C7C94` (muted grey-purple)
- Muted/disabled: `rgba(80,70,100,0.45)`
- Active/nav: `#111` (weight 600)
- Inactive/nav: `#444` (weight 500)
- Eyebrow accent: brand gradient or `#5647E0`

## Rules
1. Never mix more than 3 sizes on a single screen section.
2. Eyebrow labels are always UPPERCASE + letter-spacing ≥ 0.07em.
3. Body text line-height: 1.6.
4. Heading line-height: 1.2.
5. Use weight (not size) to create secondary hierarchy within the same scale step.
